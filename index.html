关于我

你好！我是 Alex，一名热爱技术的全栈开发者。我有 8 年的开发经验，专注于构建高性能、用户友好的 Web 应用。

我相信好的代码不仅要能运行，还要优雅、可维护。在日常工作中，我热衷于探索新技术，从 React Server Components 到 LLM 应用开发，始终保持学习的热情。
